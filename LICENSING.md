# KPA1500 Control licensing

On October 27, 2026, the project owner confirmed authority to license the KPA1500 application code and artwork and selected the MIT License. The root LICENSE records the project grant with copyright attributed to Greg Miller (NY6C), consistent with the existing application attribution.

The MIT grant applies to the project-owned application code, documentation and artwork. Preserve existing copyright and attribution notices. Bundled third-party code, native libraries and runtimes retain their own licenses and notices under ThirdPartyNotices; the application license does not replace or relicense those components. The Windows packaging audit checks both the application LICENSE and the existing pinned dependency notice inventory.

Windows bundles include LICENSE beside the executable and inside _internal, with README-Windows.txt beside the executable. The full application folder must be distributed together, including its dependency notices. The existing 57-file dependency inventory remains unchanged by this licensing decision.

Elecraft and KPA1500 identify the supported hardware; no manufacturer endorsement is claimed. The application license does not grant rights in third-party names or trademarks.

This step prepares local licensing files. It does not publish or sign a release, adopt a Store agreement, or change hardware-access authorization.
